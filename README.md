# HD Wallet Explorer

Полностью локальный open-source обозреватель HD-кошельков.

## v0.7.0

- Ethereum: адреса по пути `m/44'/60'/0'/0/N`.
- Bitcoin mainnet/testnet: BIP44, BIP49, BIP84 и BIP86.
- Локальная генерация диапазонов и публичный сканер баланса.
- Watch-only режим без seed-фразы и приватных ключей.
- Импорт `xpub`, `ypub`, `zpub`, `tpub`, `upub`, `vpub`.
- Генерация external/change адресов до 1000 за операцию.
- Сохранение только публичных watch-only профилей в браузере.
- Экспорт адресов в CSV и JSON.

## Watch-only

Откройте вкладку **Watch-only**, вставьте расширенный публичный ключ аккаунта, выберите ветку `External` или `Change`, начальный индекс и количество адресов.

Поддерживаемые форматы:

- `xpub` / `tpub` — Legacy;
- `ypub` / `upub` — Nested SegWit;
- `zpub` / `vpub` — Native SegWit.

Taproot watch-only пока не включён: обычный `xpub` не содержит однозначной информации о типе адреса, поэтому для него потребуется отдельный выбор политики BIP86.

Сохранённые профили содержат только имя, расширенный публичный ключ и дату создания. Seed, passphrase и приватные ключи в профиль не попадают.

## Как запустить

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Как запустить сканер

1. Выберите Ethereum или Bitcoin.
2. Откройте «Диапазон и сканер».
3. Введите BIP39-фразу или загрузите демо-фразу.
4. Сформируйте диапазон адресов.
5. Для Bitcoin уже подставлен Esplora API `mempool.space`. Для Ethereum укажите JSON-RPC URL, разрешающий запросы из браузера через CORS.
6. Подтвердите отправку публичных адресов и нажмите «Запустить сканер».

## Безопасность сетевого режима

Сетевой режим выключен по умолчанию и требует явного согласия. В RPC/API отправляются только публичные адреса. Mnemonic, BIP39 passphrase, seed, приватные ключи и WIF не передаются в сеть.

Для внешних endpoint разрешён только HTTPS. HTTP допускается только для localhost. URL с логином и паролем отклоняются.
