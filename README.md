# HD Wallet Explorer

Полностью локальный open-source обозреватель HD-кошельков.

## v0.6.0

- Ethereum: адреса по пути `m/44'/60'/0'/0/N`.
- Bitcoin mainnet/testnet: BIP44, BIP49, BIP84 и BIP86.
- Локальная генерация диапазона до 100 публичных адресов.
- Рабочий публичный сканер баланса и истории.
- Ethereum JSON-RPC и Bitcoin Esplora-compatible API.
- Gap limit, остановка, таймауты, повторные запросы и регулируемая пауза.
- Прогресс, сводка найденных адресов и экспорт CSV/JSON.

## Как запустить сканер

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`, затем:

1. Выберите Ethereum или Bitcoin.
2. Откройте «Диапазон и сканер».
3. Введите BIP39-фразу или загрузите демо-фразу.
4. Сформируйте диапазон адресов.
5. Для Bitcoin уже подставлен Esplora API `mempool.space`. Для Ethereum укажите JSON-RPC URL, разрешающий запросы из браузера через CORS.
6. Подтвердите отправку публичных адресов и нажмите «Запустить сканер».

## Безопасность сетевого режима

Сетевой режим выключен по умолчанию и требует явного согласия. В RPC/API отправляются только публичные адреса. Mnemonic, BIP39 passphrase, seed, приватные ключи и WIF не передаются в сеть.

Для внешних endpoint разрешён только HTTPS. HTTP допускается только для localhost. URL с логином и паролем отклоняются.
